What is protected

Code blocks, paragraphs with links, images or equations, and short table cells are left alone. Each rewritten section is checked for dropped numbers, dates, names, citations and URLs. If anything is missing, that section is sent back once with a note naming what was lost. If the second attempt still loses it, the original wording is kept and the section is marked so you can see why.
